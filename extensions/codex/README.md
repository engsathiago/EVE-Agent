# EVE Codex

Official EVE provider and harness plugin for OpenAI Codex app-server integration. It exposes the Codex-managed GPT model catalog and the Codex runtime surfaces used by EVE agents.

Install from EVE:

```bash
eve plugin add @eve/codex
```

Use this plugin when you want EVE to run Codex-backed model turns, media understanding, and prompt overlays through the Codex app-server harness.
